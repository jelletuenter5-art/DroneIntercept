# DroneIntercept — Alpine Drone Lab

A single-file Three.js drone simulator game.

## Key facts
- **Main file:** `index.html` — all game code lives in one `<script type="module">` block inside it
- **Renderer:** Three.js WebGL with ACES filmic tonemapping, instanced meshes for forests
- **Physics:** 120 Hz fixed-step, interpolated rendering
- **Terrain:** FBM fractional Brownian motion via `terrainHeight(x, z)`
- **Arena:** `ARENA` = 4200 → playable square ±4.2 km (8.4 km). Terrain mesh `WORLD` = 2·(ARENA+1300), mountain wall just outside ARENA, map `MAP_WORLD` = 2·ARENA+500 with the boundary drawn. Nothing may leave: drone/scouts/aircraft look ahead and turn back in time; if anything does cross it picks a random point well inside and returns with a brisker (but smooth) turn (`returning` flag / `state.borderPt`). Invisible backstop clamp at ±(ARENA+400) behind the mountains. Map estimates (`trackPos`) are dead-reckoned in 1 s steps with the same border logic: if the projected path would reach the border the estimate turns back towards a per-track random point inside, and never comes closer than 150 m to the border (also unknowns). Uncertainty circles are clipped to the area; labels flip left near the right border. Real aircraft start returning 250 m before the border. Light aircraft fly between destinations inside. **Exception — airliners are through-traffic** (user choice): ~650-720 km/h straight across (`transit`), spawned beyond an edge (`spawnTransitAirliner`), removed once they've left (`removeAmbient`); their tracks/estimates are hidden once outside. `randInside(m)` helper.

## Drone flight model
- `modeBlend`: 1 = VTOL hover (nose up), 0 = cruise (nose forward) — coupled to airspeed
- `state.launchStage`: `parked` → `takeoff` → `active`
- `craftInner` group inside `craft` group handles model orientation

## AI / contacts
- `scouts[]` — spawnable enemy scouts (light/heavy/fast)
- `ambientActors[]` — birds, airliners (`type:'plane'`) and light hobby aircraft (`type:'cessna'`, `createLightPlane`, scaled 1.6 → ~18 m span, liveries 50 % black / 25 % white / 25 % red, confusable with prop scouts) — civilian, never engage
- `state.pursuitMode` — false = classify loop, true = user-selected pursuit
- `state.ignoredTargets` Set — contacts drone won't re-approach
- `identifyContact(c)` — forces a confident, *correct* classification (used for tests); normal play classifies via `classifyTick`
- `radarScan(h)` — every 0.35 s: radar detection (`c.detected`), track update (`c.trk`), classification readings

## Map / HUD
- **Layout (compact, on request):** slim 40 px header = brand · status (time/weather/wind) · toolbar (`homeBtn` ⌂ Home = return to base any time while there's battery, '✕ Cancel RTB' while en route, disabled on the pad/landing — `homeButton()`, same as key B; `cameraBtn` view, `thermalBtn`, `recordBtn` ● Rec, `replayBtn`, `pauseBtn`, `settingsBtn` ⚙). No bottom bar. **Settings drawer** (`#settingsDrawer`, ⚙ or H, Esc closes) with tabs: Controls (all hotkeys in one table — keep it updated when adding keys), Environment (`#envPanel` lives here), Simulation (step, slow motion, palette, spawn `quickScoutType`/`spawnScoutQuickBtn`, terminate, reset). Contact readout + TERMINATE button at top centre; event log max 4 lines; radar panel = radar + Map button; gimbal window left of the radar.
- Map overlay: `position:fixed; z-index:999`
- `#trackConfirm` popup: `position:fixed` — uses screen coordinates from getBoundingClientRect
- Thermal imaging: IRON / WHITE-HOT / BLACK-HOT palettes
- Telemetry CSV export on stop-record or on crash

## Behaviour rules (agreed with the user)
- **Operator flags are final:** a contact flagged ★ Threat / ★ Civil (`c.userMark`) is never inspected by the AI again — skipped as a candidate, added to `ignoredTargets`, and dropped at once if it was the current investigation (pursuit can still be ordered from the map).
- **Flight nudges (on request):** W/S climb/descend (persistent `state.altBias`, never below the terrain-clearance floor), A/D turn while held (`G_.nudgeRate`, full search bank); on release the search continues straight ahead from the new heading (new `searchWp` 1.5 km ahead, altitude kept). Only while the AI is just searching — not investigating, pursuing, on a manual waypoint or going home; then the keys are ignored and the log says why. When the AI picks up an unidentified contact it takes over (nudge state + altitude bias cleared). Flight state 'SEARCH · MANUAL NUDGE'. Keys cleared on window blur.
- **Classify loop:** drone investigates radar contacts (`c.detected`) not yet classified to ≥85 %; done when conf ≥ .85, a close look (< ½ classify range) or 45 s → `ignoredTargets`. No candidates → random search waypoints (`pickSearchWaypoint`).
- **Radar & tracks:** `radarRange()` 1.5 km clear / 1.2 mist / 0.9 rain × radar cross-section `RCS` (birds .45, prop .6, jet .7, heavy .85, airliner 1.4 → `radarDetectRange`), terrain-masked (`losPoint`). One sweep per second (`RADAR_SWEEP`); plots are noisy (≈6 m + 1.5 % of range) — map/radar panel show the plot (extrapolated between sweeps), never the true position. Track `c.trk` {pos, vel, turn rate w, seen, lost}. Off radar: `trackPos()` dead-reckons along the measured turn (30 s) then straight; `trackSigma()` grows to ~1.5 km (rough guess after ~3-4 min). Track dropped when the drone gets within 100 m of the estimate and nothing is there, when the whole uncertainty area is swept and empty for 2 s, or after 10 min. The map never draws anything at a target's true position — only live radar plots or estimates. Pursuit of an undetected target flies to the estimate (phase 'search'); dropped track ends pursuit.
- **Identification** (UI always says *identified*, never *classified*): `classifyTick` (every 0.35 s, needs line of sight, independent of radar) — readings only while the object is unidentified, the active target (`state.aiTarget`), or seen up close (blur < .3, e.g. a fly-by); otherwise its % is frozen. While active/close, old votes decay (20 s → 3 s when right in front) so a good look corrects a wrong guess. Quality = sensorQuality(c) × (1 − blurAmount) — i.e. what the sensor actually resolves. camera best in clear daylight, ~15 % at night, poor in mist/rain; thermal ~78 % day or night, better in mist/rain, best on hot engines. HUD 'SENSOR … ID QUALITY x%' line under Flight State; confusions `CLS_CONFUSE`; votes → `c.guess` + `c.conf`; identified at ≥ 60 %; reclassification logged. Map/HUD/popup always show guess + %, never truth. Collision with airliner/birds = CIVILIAN INCIDENT (+ Mission Status counter). Big bottom-centre TERMINATE button during pursuit (key X).
- **Map:** radar coverage ring; home pad ⌂ with dashed line + 'HOME · x km' distance; compass rose top-right, placed inside the area boundary relative to `worldToMap(ARENA, −ARENA)` (north = map up = −Z, east = +X) with the drone's heading marker + 'HDG xxx°'; live tracks solid, estimates faded with dashed uncertainty circle + age; unclassified = grey fuzzy blip (not selectable); classified = guess + % (threat guesses orange). Click empty map → manual waypoint (radar ignored until arrival). "✕ Waypoint" cancels and resumes search from the current position.
- **Ending a chase** (terminate, track lost) adds the target to `ignoredTargets` so the drone doesn't go back to it. Search waypoints inside the turn circle are re-picked (no orbiting).
- **Pursuit:** click an identified contact on the map → Yes/No popup (`#trackConfirm`, z-index above the map) → `pursuitMode` chase until collision. `endPursuit()` clears it. Any collision → `impact()`: both explode and vanish → slow-motion replay → `resetToPad('intercept')` (needs Launch again).
- **Takeoff:** `state.takeoffT`, ~8 s: vertical climb 0–2.5 s, pitch-over to cruise 2.5–7.5 s. Launch card hides on click.
- **Energy & stall:** `thrustAccel(V)` (falls with speed), climbs cost full g·sinγ, `inducedDecel(V,n)` in turns; throttle feeds these forward but is thrust-limited, so steep climbs / max-g turns bleed speed. `V_STALL` 31 m/s ×√n; below it `state.stalled` → wings level, nose −26°, recover above 1.3×V_STALL; HUD '⚠ STALL'. AI is energy-aware (bank limited so stall speed ≤ V/1.3, climb limited to spare thrust when slow); `V_MIN` 38 is the lowest commanded speed.
- **Flight model (active):** point-mass aircraft — airspeed `state.cruiseSpeed`, heading `rot.y`, bank `state.bank`, flight-path angle `state.gamma`; velocity always along the flight path, nose = gamma + AoA, roll = bank. Envelope consts `V_CRUISE` 69 m/s (~250 km/h, efficient search), `V_DASH` 111 (400 km/h, pursuit only), `V_MIN` 30, bank 65°/73°, climb/dive 22°/26° (pursuit ~31°/37°). Guidance fills `guide` (aim, alt, speed, bank, track/tau/ff for pursuit altitude).
- **Altitude planning:** one cruise altitude per leg from `routeFloor()` (max terrain on the straight route) → constant-slope climb/descent that arrives at the goal altitude; short lookahead `routePeak` only as safety.
- **Attack (`attackGuidance`):** rear-slot steering — aim at a point riding behind/beside the target on its *predicted turn arc* (`predictContact`/`solveRendezvous`), weight `wL` fades to 0 once committed behind (`commit`: behind AND same heading; inside 450 m rear half is enough) → collision course. Speed: far behind → catch up, arriving at the tail (~350 m) at +10 m/s; then, only once established on its tail (`onTail`), closure builds steadily from +10 to +32 m/s at impact (sure hit); turn-radius-fitted speed while converting. Altitude: copy target climb rate (`ff`) + null height error by arrival (`tau`), side offset (above 70% / below) collapses to 0 inside 40 m. HEAD-ON only when CPA geometry lines up. Phase label (INTERCEPT/JOINING TAIL/CLOSING IN/HEAD-ON) in Flight State.
- **Benchmark:** deterministic 30-geometry engagement test (targets start 0.9–2.2 km, i.e. often beyond radar): 30/30, mean ≈36 s, ≈10 % battery, 0 S-shapes; also 30/30 at 6 and 13 m/s wind. Re-run something similar after touching guidance.
- **Anti-weave:** close-in augmented proportional navigation (`G.rateCmd`), gentle braking-limited closure (slower while target turns), bank-reversal detection → settle at Vt+3.
- **Scouts** have personal height bands (`scoutBand`: low 45-110 / mid 120-260 / high 280-480 m AGL — low ones are often terrain-masked from radar) and fly fixed-wing kinematics: constant speed, ≤30° bank, roll rate ~20°/s, climb ≤~8°, at their listed `SCOUT_SPEC` speed (no hidden multipliers); hard ×1.15. Waypoints inside their turn circle are flown past (no endless orbiting); waypoints kept within ±2200 m.
- **Log:** `logEvent()` feed under Flight State (left); `toast()`/`radioMessage()` both write to it; entries fade after 5 s. Top toast and bottom banner are hidden.
- **Battery:** gauge sits in the bottom-left HUD box (bottom-right was under the radar). Power = `flightPower(V, bank, vs)` ∝ V^2.3 (drag) + turn load + climb; `BATTERY_WH` = 57 (halved on request): ~5 min of search, ~2 min of continuous 400 km/h dash, ~20 % per chase. `drainBattery()` → at 0 `startBatteryFailure()` → `stepPowerLoss()` unpowered fall with momentum → crash → `resetToPad('battery')` (full battery, identifications cleared).
- **Turning:** yaw rate limited by coordinated-turn physics `g·tan(bank)/v` (65° bank in search, 73° in a chase); roll matches the turn.
- **Mission Status (top right):** POTENTIAL THREATS (tracked objects whose guess is a scout) · TOTAL IDENTIFIED OBJECTS · CIVILIAN INCIDENTS (if any). No 'threats left' (removed on request).
- **Wind:** `updateWind()` mean (auto per weather `WEATHER_WIND`, or Environment panel) + gusts + vertical turbulence in `wind` vector. Drone, scouts (`s.vel` = ground velocity; air = `s.hdg`/`s.spd`) and airliners drift; `crabHeading()` corrects crosswind; search airspeed +0.45×headwind. HUD: airspeed + GS; header shows time, weather, wind.
- **Environment panel** (☁ button): weather Auto/fixed, wind auto/speed/from-direction, gusts, time of day (manual or running). `env` object.
- **Replay:** `recordFrame` 30 Hz ring buffer (8 s) of drone + objects within 500 m. `impact()` freezes it into `state.lastReplay`; `startReplay` pauses sim, `stepReplay` plays in real time (no slow motion, on request): two angles only: chase cam → impact cam (last 2 s) → explosion hold. Every cut frames drone AND target; target marked with a projected 'TARGET' box. Skip via the 'Skip replay' button (or Space/Esc) — not by clicking the view. "⟲ Replay last impact" button. HUD hidden (`body.replaying`). Propellers, drone rotors and bird wings keep moving at replay speed; aircraft bank recorded. Playback advances on true wall-clock time (`rawDt`, capped 0.5 s), never the 0.1 s physics cap — so heavy frames can't make it look slow-mo.
- **Distance blur (real optical blur):** `updateContactViews()` each frame. `shapeRange(c)` = `SHAPE_RANGE` (prop 800, jet 850, heavy 1000, airliner 1200, birds 440 m) × sensor quality factor; `blurAmount` = smoothstep(0.15R, 1.6R, d). Beyond `visualRange` (1.4×shapeRange) nothing is drawn; contacts fade in over its last 25 % (no glare: haze fades them out instead of tinting them bright). Sharp (<0.02) → real model in the scene. Otherwise the model is rendered alone into its own 128² mipmapped render target (`impScene`, `impCam` framing its bounding sphere) and shown on a camera-facing card whose shader samples with LOD bias = blur×6.5 (+ round mask, fog, thermal atmospheric attenuation / camera night visibility). A bird flock is one image: birds merge far away and separate when close (birds spread ±22-26 m). Readout temps only when blur < .35. Replay re-attaches models and hides cards.
- **Traffic:** `spawnRandomTraffic()` every 15-45 s while flying: scouts (cap 6), bird flocks (cap 7) or airliners (cap 4), 1.6-2.6 km from the drone, unannounced.
- **Aircraft lights** (airliners): red left / green right wingtip, white tail, red flashing beacons, white double strobes — glow sprites (`addAircraftLights`, `updateAircraftLights`), bright at night, strobes faint by day, hidden in thermal, visible even when the aircraft is a blurred dot.
- **Explosions:** `explodeAt(pos, scale, vel, tint)` flash + fireball + rising wind-drifting smoke + tumbling debris (momentum, smoke trails, dust on landing, lies ~13 s); `disposeExplosion`. Sound `boomSound(pos)`: delayed by distance/343 m/s (not in replay), distance low-pass, layers crack + roaring body sweep + long rumble + sub thump + debris crackles.
- **Clouds:** `cloudBanks` (20 ellipsoids at 300-650 m, drift with wind; share present = `cloudCover()` rises with weather). `cloudDensity`, `cloudBetween`: inside → white-out fog, `state.cloudHere` cuts sensor quality (camera ×0.1, thermal ×0.5); cloud between drone and contact blocks camera ID (thermal partly) and hides the contact visually; radar unaffected.
- **Impostor orientation:** blur camera = main camera rotated minimally onto the object (no lookAt/up-vector flips); the card uses the same quaternion.
- **Spawn menu** includes Light aircraft (civil), random livery.
- **Gimbal zoom camera (PiP, bottom right next to radar) — fully manual (on request):** `zv`, `renderZoomView` renders the scene again with `zoomCam` into `#zvFrame` (scissor). World-stabilised gimbal: `zv.yaw`/`zv.pitch` only change by operator input (drag inside the window, arrow keys; V/⌖ re-centre on the nose); gimbal stop ±150° from the nose (`GIMBAL_LIMIT`) pushes it round. No target picking from the map, no auto-lock (so estimates can't be 'spotted' for free). Zoom 1-30× (wheel / + −, Z hides); effective zoom `zv.zEff` = 1+(zoom−1)·clarity(sensor quality); shake ∝ zoom; drone hidden in its render. Contacts re-rendered for it via `updateContactViews(zoomCam, zEff)`. Anything inside its field of view gets d/zEff in `classifyTick`. `findInScope` = visible contact inside the square reticle (laser range shown, no free identification). ★ Threat [1] / ★ Civil [2] (hotkeys 1 and 2) set `c.userMark` on the in-scope contact; if it had no track it becomes a visual sighting (track from where it was seen) and can be pursued. Drag fix: `#zvFrame` blocks native dragstart/selection (otherwise the browser shows a 'no-drop' cursor and swallows the drag).
- **Return to base:** `rtbRequired()` = (cruise power × distance / ground speed into the wind + `LAND_POWER`×`LAND_TIME`) × 1.15 / `BATTERY_WH`, every 1 s → `state.rtbNeed` (yellow marker on the battery bar). `#rtbCard` at +10 % (advisory, chime), +5 % (urgent red, alarm), 0 % (BINGO); Return to base / Dismiss; key B. `acceptRtb` → `state.rtb='enroute'` (ends pursuit, no new investigations). **En route altitude:** one smooth profile — `state.rtbFloor` = highest terrain on the remaining route (except the last 300 m), re-planned 1×/s, goal = max(floor + 110, glide 70 m + 8 % beyond 450 m) eased into `state.rtbAlt`, flown with a fixed `G_.tGo` = 7 s (no track mode, no stepping goal → no pitch hunting over mountains; the old version flipped pitch 100+ times). Shared vertical dead-band is continuous (no hunting at ±6 m). **Landing (`'landing'`, physical, on request):** starts once inside the braking distance (V²/3.2 + 60 m) *and heading for the pad*; aim = random point ±3 m from centre on the 30 m pad (ring + H). Approach: braking profile √(2·1.6·(d + float)) with a lagging velocity loop — it deliberately judges the stop 5-12 m long (`landFloat`) so it slides past the spot and comes back; glide descends to reach 25 m over the spot. Hover: under-damped PD (overshoot → correct) within 12 m, braking-profile 'reposition' beyond (no pendulum), accel ≤ 3.5 m/s², gusts push it. Descends once settled (or after 10 s), keeps correcting, slows near the ground; touchdown at its real x/z ('TOUCHDOWN · x m from centre'). Attitude: nose up into hover as speed drops (`modeBlend`), yaws into the direction of travel, whole airframe tilts towards its acceleration about a world axis (`state.tiltX/tiltZ` → quaternion in `updateVisuals`). `LAND_TIME` 65 s. Verified: 24/24 landings from 3.5 km at 0/8/13 m/s wind, 0.4-7.7 m from centre, 40-70 s; starting with exactly the reserve it lands with 9-19 % left. Flight-state text: APPROACH · BRAKING / HOVER · CORRECTING / LANDING.
- **Flares:** `fireFlares`/`updateFlares` — pursued scout fires salvos (3, 7-12 s apart) when the drone is <700 m in its rear half. `flareGlare(p)` degrades thermal ID; with thermal ON the pursuit aim is decoyed toward the flares for ~2.2 s (`state.decoyUntil`, phase 'decoyed'); the camera is not fooled.
- **Sun glare (mild):** `sunW` (sun dir), `sunGlareAt(dir)` (camera only), soft `#glare`/`#zvGlare` overlays, ID quality ×(1−0.45·glare) near the sun.
- **Sound:** synthesised WebAudio (`audio`, `initAudio` on first gesture): flight group (engine/prop hum ∝ airspeed & power, hover rotor buzz, wind), fx (`playSfx` ping on new track, lock tone in join/terminal, boom, flare, slap), alerts (chime, alarm, stall horn). Settings → Audio tab volumes (master/flight/fx/alerts, mute; localStorage `dl_audio`); key U mutes.
- **Mission debrief:** `missionLog(ev, c)` (start on launch, identified, flag, pursue, endPursuit, hit, crash, rtb) + `missionSample` path every 1.5 s. `showDebrief(reason)` from `resetToPad` for landed / intercept / battery: card with header stats + score, flight-path minimap (`drawDebriefMap`), identifications vs ground truth, calls you made (✓/✗), engagements; sections slap in (CSS `.slap`, entrance only); Continue (Enter/Space/Esc). Debrief map shows only the flight path, HOME and the end point (✕ COLLISION / AIRCRAFT LOST; nothing extra after landing); `state.mission.end` is set in `resetToPad` so the path ends where the sortie ended (no loop back home).
- **Free camera:** orbit relative to smoothed heading, eased targets + drag inertia, exponential wheel zoom (6–260 m), double-click resets.
